# 🎮 GameZone

O **GameZone** é um site informativo desenvolvido com foco na estruturação semântica em **HTML5**, sem uso de frameworks ou bibliotecas externas. A plataforma centraliza informações, estatísticas, conteúdos multimídia e formulários de avaliação sobre os principais jogos eletrônicos do mercado.

---

## 📂 Estrutura de Páginas

| Arquivo | Descrição |
| :--- | :--- |
| `Homepage.html` | Página inicial com apresentação e lista de jogos populares. |
| `jogos.html` | Catálogo detalhado contendo trailers incorporados do YouTube e plataformas. |
| `ranking.html` | Classificação Top 5 de jogos com vídeo e notas. |
| `sobre.html` | Informações institucionais do projeto, objetivos e dados de contato. |
| `formulario.html` | Formulário completo para envio de avaliações de jogos pelos usuários. |
| `minecraft.html` | Página individual com detalhes, áudio e vídeo do jogo *Minecraft*. |
| `rdr_2.html` | Página individual com detalhes, áudio e vídeo do jogo *Red Dead Redemption 2*. |
| `zelda.html` | Página individual com detalhes, áudio e vídeo do jogo *The Legend of Zelda: Breath of the Wild*. |
| `fortnite.html` | Página individual com detalhes, áudio e vídeo do jogo *Fortnite*. |
| `gta_v.html` | Página individual com detalhes, áudio e vídeo do jogo *GTA V*. |

---

## 🛠️ Recursos HTML5 Utilizados

* **Estruturação Semântica:** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`.
* **Mídia e Incorporação:** `<figure>`, `<figcaption>`, `<img>`, `<audio>`, `<video>`, `<iframe>`.
* **Formulários e Entradas:** `<form>`, `<fieldset>`, `<legend>`, `<input>` (text, date, color, range, radio, checkbox, file), `<datalist>`, `<textarea>`, `<button>`.
* **Indicadores de Dados e Interatividade:** `<meter>`, `<progress>`, `<details>`, `<summary>`.
* **Marcação de Texto e Acessibilidade:** `<mark>`, `<abbr>`, `<blockquote>`, `<cite>`, `<address>`, atributos `alt` em imagens e navegação padronizada.

## 🚀 Como Executar

1. Baixe ou clone os arquivos do repositório mantendo a hierarquia de pastas.
2. Abra o arquivo `HTML/Homepage.html` em qualquer navegador web moderno.
3. Utilize o menu de navegação localizado no cabeçalho para alternar entre as páginas.
